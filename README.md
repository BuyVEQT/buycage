# BuyCage

Site for [buycage.ca](https://buycage.ca) — CAGE ETF investor hub (planning phase).

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- TypeScript

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Status

Minimal scaffold — design pass in Claude Design pending before content build-out.
